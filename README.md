# Mood News Grid 📰🎭

Прототип новостного веб-приложения, которое позволяет читать одни и те же реальные новости в разных эмоциональных окрасках (радостно, грустно, иронично, нейтрально). Главная особенность — изменение подачи текста без искажения исходных фактов.

## 🚀 Как запустить проект

Проект разделен на две части: скрипт для сбора данных и легковесный фронтенд для их отображения.

**Запуск интерфейса (Frontend):**
Приложение работает без сервера. Чтобы посмотреть результат:

1. Склонируйте репозиторий.
2. Откройте файл `index.html` в любом современном браузере. Данные уже сгенерированы и загружаются из файла `news_data.json`.



**Обновление базы новостей (Backend/Парсер):**
Если вы хотите загрузить свежие новости, потребуется запустить Python-скрипт:

1. Установите зависимости: `pip install feedparser openai`.
2. Откройте файл `parser.py` и вставьте ваш действующий API-ключ в переменную `client` (вместо `YOUR_KEY_API`).


3. Запустите скрипт: `python parser.py`.
4. Скрипт соберет новости, прогонит их через ИИ и обновит файл `news_data.json`.

## 📡 Откуда берутся новости

В качестве источника реальных новостей используется открытая RSS-лента Хабра (`[https://habr.com/ru/rss/news/?fl=ru](https://habr.com/ru/rss/news/?fl=ru)`). Сбор данных осуществляется на стороне Python с помощью библиотеки `feedparser`. Скрипт берет свежие публикации, очищает описание от HTML-тегов и забирает первые 10 записей для обработки.

## 🗄️ Как устроено хранение данных

Для хранения используется NoSQL-подход в виде статичного файла `news_data.json`.

* Это позволяет фронтенду работать быстро и без необходимости поднимать полноценную базу данных.


* Каждая новость сохраняется в виде структурированного объекта, содержащего заголовок, ссылку на источник (`link`), дату публикации и вложенный объект `moods`, где лежат заранее сгенерированные тексты для каждого настроения (`neutral`, `optimistic`, `sad`, `ironic`).

## 🤖 Использование AI и переписывание тона

Для генерации текстов используется нейросеть через API, совместимое с OpenAI.

* **Модель:** В скрипте задействована модель `glm-4.7-flash` от платформы Z.ai (эндпоинт `[https://api.z.ai/api/paas/v4/](https://api.z.ai/api/paas/v4/)`).


* **Логика:** Скрипт в цикле перебирает собранные новости и отправляет их в LLM поочередно для каждого требуемого настроения. Между запросами установлена пауза (`time.sleep(1)`), чтобы избежать блокировок по лимитам.

## 🛡️ Как проверяется сохранение фактов

Сохранение фактов (имен, дат, цифр) — критическое требование проекта. Оно контролируется на двух уровнях:

1. **Системный промпт (Prompt Engineering):** Нейросети передается жесткая инструкция на уровне `system_prompt`. В ней прописано «КРИТИЧЕСКОЕ ПРАВИЛО: Ты обязан сохранить все факты на 100%. Не изменяй и не удаляй: имена, даты, числа, названия компаний, географические объекты, прямые цитаты. Меняй только эмоциональную окраску текста, эпитеты и стиль подачи.».


2. **Визуальная проверка (UI):** В интерфейсе реализовано модальное окно. По клику на любую карточку с новостью открывается экран сравнения, где рядом выводятся исходный (оригинальный) текст и переписанный ИИ текст в выбранном настроении. Это позволяет пользователю лично убедиться, что цифры и суть новости остались неизменными.
